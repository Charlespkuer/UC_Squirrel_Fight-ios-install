UC 松鼠大战 · iOS 存档救援

先救存档

企业证书已被 Apple 吊销：旧安装包现在打不开、也装不上。
存档还在手机里，按下面的顺序做。

最重要：不要删除「松鼠大战」App。
删除 App 会连它的存档容器一起删除；重新装同一个企业包也救不回来。
发生了什么：Apple 在 2026-10-23 16:05 UTC 把这张企业证书置为 revoked（certificateHold）。这不是「未受信任」，也不是描述文件到期—— 重新信任、重启、覆盖安装同一个 IPA 都不会恢复。描述文件本身也会在 2026-11-05 到期。
网页版 / PWA 已上线：不用证书。iPhone / iPad 用 Safari 打开 → 分享 → 添加到主屏幕；先安装，再从游戏里「系统 → 导入存档」导入。 主屏幕 Web App 和 Safari 的存储是隔离的，先玩过 Safari 的话先在 Safari 里导出。
打开网页版 / PWA →

第 0 步：先确认你属于哪一种

  1. 以前在游戏里点过「导出存档」 → 看第 1 步，最简单，不用电脑。
  2. 没有导出过，但游戏还装在手机上 → 看第 2 步，用电脑把存档拿出来。
  3. 已经删了 App / 恢复过手机 / 没有任何备份 → 看第 4 步，希望较小。

第 1 步：在「文件」App 里找导出档（不用电脑）

  1. 打开「文件」App → 「浏览」→ 「我的 iPhone / iPad」。
  2. 找「松鼠大战」文件夹，里面应该有 松鼠大战存档-....json。
  3. 长按最新的 .json → 「拷贝」→ 拷到「iCloud 云盘」或「我的 iPhone」里的其它文件夹。
  4. 先留着这个文件；按第 3 步导入网页版。

如果文件夹是空的：说明没手动导出过，走第 2 步。即使 App 打不开， 「文件」App 里的这个文件夹通常还在，值得先看一眼。

第 2 步：没有导出档 → 用电脑取出 App 沙盒里的存档

存档文件在 App 沙盒的：

Library/Application Support/com.ssdz.classic/save/progress.json

它是普通 JSON，不需要解密。旁边还有 progress.bak.json（备份档）。三种取法，按你的电脑选：

下面的命令假设你在本仓库根目录（脚本在 rescue/ios-save-rescue.cjs）； 如果只下载了脚本，把路径换成脚本实际位置，例如 node ~/Downloads/ios-save-rescue.cjs。

2A. Mac + Xcode（推荐，最直接）

  1. Mac 安装 Xcode（App Store 免费），用数据线连接 iPhone，手机上点「信任」。
  2. Xcode → Window → Devices and Simulators → 选你的 iPhone → 等它连上。
  3. 在 Installed Apps 里找「松鼠大战」→ 齿轮 / 右键 → Download Container… → 保存为 .xcappdata。
  4. 把下载到的 .xcappdata 交给救援脚本：
    node rescue/ios-save-rescue.cjs --container ~/Downloads/松鼠大战.xcappdata
  5. 脚本会输出「松鼠大战存档-救援-*.json」。

Xcode 各版本界面略有不同；找不到 Installed Apps 时，用下面的命令行。

命令行版（Xcode 15+，需要开发者模式） 
xcrun devicectl list devices
xcrun devicectl device copy from \
  --device <UDID> \
  --domain-type appDataContainer \
  --domain-identifier jp.co.rakuten-sec.iSPEED.Pushnotification.widgetapp.widgetkitextension \
  --source . \
  --destination ~/Downloads/松鼠大战容器

然后把 ~/Downloads/松鼠大战容器 交给脚本：

node rescue/ios-save-rescue.cjs --container ~/Downloads/松鼠大战容器

第一次用会提示在手机上开启「开发者模式」，开启后重启手机。设备要解锁、保持连接。

2B. Mac / Windows + 本地备份 + 救援脚本

  1. Mac：Finder → 你的 iPhone → 「立即备份」。不要勾「加密本地备份」（勾了脚本读不了；除非你用 iMazing 并输入密码）。
    Windows：Apple Devices / iTunes → 设备 → 「立即备份」，同样不要加密。
  2. 找到备份目录：
    Mac：~/Library/Application Support/MobileSync/Backup/<UDID>
    Windows：%APPDATA%\Apple Computer\MobileSync\Backup\<UDID> 或 %USERPROFILE%\Apple\MobileSync\Backup\<UDID>
  3. 运行（需要 Node.js 22.5+）：
    node rescue/ios-save-rescue.cjs --backup "<备份目录>"
  4. 输出目录里会有「松鼠大战存档-救援-*.json」。

备份包含整台手机的数据；脚本只读游戏存档，不联网、不上传。提取完请把备份和输出文件收好，别发到公开群。

2C. 图形工具（不想用命令行）

iMazing / 3uTools / iExplorer 等可以浏览 iPhone 备份或 App 数据：选「松鼠大战」→ 导出 App 数据 → 找到 Library/Application Support/com.ssdz.classic/save/progress.json。 不同版本菜单不一样，认准这个路径即可。

如果工具只能导出整个 App 容器，把导出的文件夹交给 2A/2B 的脚本也行。

第 3 步：把存档导入网页版 / 新版本

  1. 网页版现在已经可用；原生新包（新签名 / TestFlight）等后续。
  2. 把「松鼠大战存档-救援-*.json」通过 AirDrop、「文件」App 或微信文件传输助手放到新游戏的 Documents：
    「文件」App → 我的 iPhone/iPad → 松鼠大战 → 粘贴。
  3. 打开游戏 → 系统 → 导入存档 → 存档列表 → 选这份 .json。
  4. 导入前先在游戏里点一次「导出存档」，给当前档留个备份；导入错了还能换回来。

如果新版本和旧版本使用同一个 Bundle ID、并且是覆盖安装，存档可能会自动留在原容器里； 仍然建议先导出备份。不同 Bundle ID 的新版本不会自动读旧档，必须走上面的导入。

第 4 步：已经删了 App 怎么办

  • 如果删 App 之后没有恢复过手机、也没有备份：iOS 已经删除了数据容器，基本无法找回。
  • 如果删之前做过 Finder/iTunes 备份：按 2B 从备份里找 progress.json，还有机会。
  • 如果整机从 iCloud/电脑备份恢复过：备份里可能还带着旧 App 的数据；用 iMazing 等工具查看备份， 或把备份恢复到一台设备后再按 2A/2B 取。
  • 不要为了「重新装一次」去删除 App；删除动作本身就会让情况更糟。

常见问题

重新信任证书 / 重启 / 重装同一个 IPA 有用吗？

没用。Apple 在 2026-10-23 16:05 UTC 把这张企业证书置为 revoked（certificateHold）， 不是「未受信任」，也不是描述文件到期。重新信任、重启、覆盖安装同一个包都不会恢复。 描述文件本身也会在 2026-11-05 到期。

装未签名版，能直接读旧企业版的存档吗？

不能。未签名 IPA 的 Bundle ID 是 com.ssdz.classic，企业版是 jp.co.rakuten-sec...；iOS 把它们当成两个 App，沙盒/存档容器互不相通。 而且 stock iPhone 根本装不了未签名 IPA。只有把未签名包改成旧 Bundle ID 再覆盖安装 （TrollStore / 重签）才可能读到旧容器；这不是普通玩家能直接做的。 稳妥做法是第 2 步取出 JSON、第 3 步导入。

删除 App 再装新版本，存档会回来吗？

不会。iOS 删除 App 时会删除它的数据容器；没有备份就找不回来。不要删。

存档到底在哪？

<App 容器>/Library/Application Support/com.ssdz.classic/save/progress.json， 旁边还有 progress.bak.json。导出的 .json 在 Documents/，会出现在「文件」App。

备份是加密的，脚本读不了怎么办？

在 Finder/iTunes 里关闭「加密本地备份」后重新备份一次；或者用 iMazing 打开加密备份并输入密码， 再导出 App 数据。

我没有电脑，也没导出过存档，怎么办？

很遗憾，单靠手机拿不到 App 沙盒里的 Application Support 文件。可以借一台 Mac/Windows 电脑， 按第 2 步做；或者联系开发者/社区里方便帮忙的人。越早做越好，别先删 App。

我不想把整台手机的备份发给别人。

不需要。救援脚本只在你自己的电脑上读，输出只有游戏存档 JSON。 不要把整份备份发到公开群；只把 松鼠大战存档-救援-*.json 发给开发者/自己。
